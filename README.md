# Token launch radar

A token launch radar for [make.fun](https://make.fun/bounty/token-radar-01)'s token-radar-01 bounty. Reads a sealed DefiLlama snapshot, ranks 197 pre-token protocols by implied launch value (TVL x category x chains x growth x maturity), and serves a static dashboard with a board, detail views, filters, and farm plans.

Run: `node main.ts` (Node 22; reads /input/snapshot.json, writes /output/board.json + dashboard + dossier.json)
